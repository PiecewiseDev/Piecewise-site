## How to Add Logos

1. Download official logos from each tool's brand assets or press kit page
2. Resize to square format (recommended: 64x64px or 128x128px)
3. Save as PNG with transparent background if possible
4. Name exactly as shown above
5. Place in `/public/logos/` directory

## Fallback

If a logo is not available, the page will show a placeholder icon in a light gray background box.

## Brand Guidelines

Make sure to follow each company's brand guidelines when using their logos.
Many companies provide official logo packs on their website under "Brand Assets" or "Press Kit".
